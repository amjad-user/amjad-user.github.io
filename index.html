Profile

Engineering at the boundaries

My focus is the connective tissue of software: interfaces, data models and the contracts that let independent systems compose without friction.

In AI systems that layer is critical. A language model is only as capable as the tools it can invoke, and tool schemas evolve without notice. I engineer tooling that detects schema drift and surfaces breaking changes before they reach production agents.

Every system I build is deliberately scoped, tested and reproducible: clone it, run it, audit it.
